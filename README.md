# KODY

Карманный мультитул-девайс: **плата расширения для Raspberry Pi Zero** с цветным
тачскрином, крутилкой, кнопками, антеннами (Sub-GHz, LoRa, 2.4 ГГц, SDR),
NFC/RFID, ИК, USB-C зарядкой, USB-A портами и выведенной наверх гребёнкой
на 40 GPIO для своих проектов.

> **Актуальная концепция — v2 «пазл»:** шесть маленьких плат вокруг Pi Zero,
> отпечаток почти как у самой Pi. Смотри [`docs/concept.md`](docs/concept.md) и
> **3D-модель с телефона:** https://claude.ai/artifact/SPZszNhs2kebLbU7mErjtX
>
> Ниже — первый разбор идеи (v1, одна большая плата). Механика оттуда устарела,
> но разбор радио/NFC/питания по-прежнему актуален.

## Это реализуемо?

**Да.** Почти всё из идеи делается на готовых и доступных компонентах.
Несколько вещей нужно сделать чуть иначе, чем задумано — коротко:

| Хотелка | Вердикт | Как именно |
|---|---|---|
| Плата, которая вставляется в Pi Zero | ✅ | Основная плата с гнездом 2×20, Pi Zero сидит на ней «бутербродом» |
| Очень хороший экран, много герц, тачскрин | ✅ с оговоркой | У Pi Zero нет DSI-разъёма. Лучший вариант: 2.8" IPS 320×240 по SPI (ST7789) + ёмкостный тач (FT6336) — **40–50 FPS**, плавно и ярко. Большой 4–5" экран возможен только по HDMI (дороже, толще, жрёт батарею) |
| Крутилка «как громкость в машине», очень плавная | ✅ | Магнитный энкодер **AS5600** + металлическая ручка на подшипнике с демпферной смазкой: без щелчков, бесконечное вращение, 4096 положений на оборот |
| 2–3 кнопки | ✅ | |
| Антенны SDR / LoRa / Sub-GHz / NRF24 | ✅ | RTL-SDR (USB), SX1262 (LoRa), CC1101 (Sub-GHz как у флиппера), NRF24L01+PA/LNA. Сзади 4 разъёма SMA |
| ИК | ✅ | ИК-приёмник + мощные ИК-диоды |
| NFC/RFID «своя плата, не PN532» | ✅ | **ST25R3916** (13.56 МГц: чтение **и эмуляция** — тот же чип, что во Flipper Zero) + схема 125 кГц на микроконтроллере |
| Слот для «сим-карты» под локальные файлы | ✅ но это **microSD** | В SIM-карту файлы записать нельзя. Делаем второй слот microSD — он отдельный от системной карты Pi |
| Зарядка по USB-C | ✅ | Контроллер BQ25895 (заряд + питание + повышение до 5 В) и Li-Po аккумулятор |
| 2–3 USB-A («квадратный, который всегда не той стороной») | ✅ | USB-хаб на плате (FE1.1s). У Pi Zero один USB, хаб размножает его |
| Все 40 GPIO наверх «мамой» | ✅ | Все 40 линий проходят насквозь на гнездо 2×20 сверху. Занятые девайсом пины подписаны на шелкографии, а программа не даст их случайно занять |
| Меню «Проекты → Лампочка → пресеты → мигание/плавно» | ✅ | Прототип уже здесь: [`software/`](software/) |

### Две важные рекомендации

1. **Возьми Raspberry Pi Zero 2 W (или Zero 2 WH)** вместо Zero WH.
   Размер и разъём те же — плата подойдёт к обоим. Но у Zero WH одно слабое
   ядро ARMv6: плавный интерфейс + SDR на нём будут тормозить. Zero 2 W в 4–5
   раз быстрее и стоит ~$15. Для первого прототипа Zero WH сгодится.
2. **Всё, что требует точного тайминга (Sub-GHz запись/повтор, NFC-эмуляция,
   125 кГц, ИК, кнопки, крутилка), повесить на сопроцессор RP2040**.
   Linux не умеет в микросекундную точность, а микроконтроллер — умеет. Так
   же сделано во Flipper Zero. Заодно это освобождает пины Pi для твоих проектов.

## Быстрый старт программы

```bash
cd software
python3 -m kody            # на ПК работает в режиме симуляции
sudo apt install python3-gpiozero && python3 -m kody   # на Raspberry Pi — реальные пины
python3 -m unittest -v     # тесты
```
