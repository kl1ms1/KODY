# KODY — аппаратная часть (ТЗ для EasyEDA)

Ревизия: v0.1 (концепт). Всё ниже — предложение, его можно и нужно обсуждать.

## 1. Общая архитектура

```
                       ┌──────────────────────────────────────────┐
  USB-C ──► BQ25895 ──►│ SYS ──► 5.1 В boost (TPS61088) ──► 5V     │
            (заряд)    │  │                                │       │
  Li-Po 1S ◄──────────►│  └─► LDO 3.3 В ──► RP2040 (всегда │       │
  3000–4000 мА·ч       │                     включён)       │       │
                       └────────────────────────────────────┼───────┘
                                                            ▼
 ┌───────────────── Raspberry Pi Zero (2) W ─────────────────────────┐
 │ 40-pin ──► проходит насквозь на верхнее гнездо 2×20 (мама)         │
 │   SPI0 ──► Экран 2.8" IPS ST7789 (CS0)                             │
 │   I2C1 ──► Тач FT6336 (общая шина, можно добавлять свои устройства)│
 │   SPI1 ──► LoRa SX1262 (CE0), microSD №2 (CE1)                     │
 │   PWM  ──► подсветка экрана, пищалка                               │
 │ micro-USB OTG ──► USB-хаб FE1.1s ─┬─► RTL-SDR (внутренний модуль)  │
 │                                   ├─► RP2040 (сопроцессор)         │
 │                                   ├─► USB-A №1  (ограничение 0.5 А)│
 │                                   └─► USB-A №2  (ограничение 0.5 А)│
 └────────────────────────────────────────────────────────────────────┘

 RP2040 (реальное время) ─┬─ SPI ─► CC1101 Sub-GHz (300–928 МГц)
                          ├─ SPI ─► NRF24L01+ PA/LNA (2.4 ГГц)
                          ├─ SPI ─► ST25R3916 NFC 13.56 МГц (чтение + эмуляция)
                          ├─ PIO ─► RFID 125 кГц (генератор + детектор)
                          ├─ PIO ─► ИК передатчик / ИК приёмник
                          ├─ I2C ─► AS5600 (крутилка), BQ25895, MAX17048 (батарея)
                          ├─ GPIO ► кнопки B1, B2, POWER, вибромотор, RGB-светодиод
                          └─ GPIO ► включение 5 В, сигнал «выключись» для Pi
```

### Почему сопроцессор RP2040

- Запись/повтор сигналов Sub-GHz, 125 кГц, ИК и NFC-эмуляция требуют точности в
  микросекунды. Linux на Pi так не может (планировщик задач «дёргает» тайминги).
  У RP2040 есть PIO — аппаратные машины состояний именно под такие задачи.
- Освобождает пины Pi под пользовательские проекты.
- Управляет питанием: RP2040 питается всегда (в сне — микроамперы), по кнопке
  включает 5 В для Pi, а при выключении сначала просит Linux корректно
  завершиться. Никакой порчи SD-карты.
- Прошивается прямо с Pi: Pi держит BOOTSEL и дёргает RUN — RP2040
  появляется как USB-диск, на него копируется `.uf2`. Обновления «по воздуху»
  вместе с обновлением ОС.
- Стоит ~$1.

### Почему USB от Pi идёт через micro-USB, а не через гребёнку

USB-линий на 40-pin разъёме нет. У Pi Zero они есть только в micro-USB
OTG-порте (и на тест-площадках снизу платы). Решение для v1: короткая
гибкая перемычка с разъёмом micro-USB (штекер), которая втыкается в порт
Pi, а другим концом паяется в нашу плату. Для v2 можно перейти на
pogo-пины к тест-площадкам PP22/PP23 снизу Pi.

## 2. Механика (по твоим скетчам)

```
 ВИД СПЕРЕДИ                          ВИД СЗАДИ
 ┌──[ 2×20 GPIO мама ]──┐             ┌──────────────────────┐
 │ ┌──────────────────┐ │[USB-A]      │ (SMA)(SMA)(SMA)(SMA) │
 │ │                  │ │[USB-A]      │ SubG LoRa 2.4  SDR   │
 │ │   2.8" экран     │ │        (O)  │                      │
 │ │                  │ │  крутилка   │   ┌────────────┐     │
 │ └──────────────────┘ │  [B1] [B2]  │   │ NFC/RFID   │ ИК  │
 │                      │             │   │ катушки    │ ◉◉  │
 └──[USB-C]──[microSD]──┘             │   └────────────┘     │
                                      │  [Pi Zero внутри]    │
                                      └──────────────────────┘
```

- Габарит основной платы ориентировочно 70×95 мм (экран 2.8" ≈ 50×69 мм
  активной области + поля).
- Крутилка — сбоку справа, ручка Ø20–25 мм выступает за корпус на 3–4 мм.
- NFC-антенна 13.56 МГц — дорожками на плате (на задней стороне), под
  ней не должно быть сплошной меди. Катушка 125 кГц — готовая намотанная
  (~700 мкГн) или тоже на плате.
- Корпус — печать на 3D-принтере (PETG), позже — литьё.

### Крутилка «как в машине»

- Датчик **AS5600** (магнитный, 12 бит) на плате + диаметральный магнит в
  торце вала.
- Вал на шарикоподшипнике (например 685ZZ, 5×11×5 мм) + капля демпферной
  смазки (как в объективах / ручках громкости) — получится тяжёлое,
  «масляное» вращение без щелчков.
- Нет механического контакта → не изнашивается, не дребезжит.
- Отдельно — нажатие: кнопка-«таблетка» под ручкой или используем B1.
- Программно можно делать «виртуальные щелчки» (вибромотор на каждый шаг).

## 3. Экран

| Вариант | Плюсы | Минусы |
|---|---|---|
| **A (рекомендую для v1)**: 2.8" IPS 240×320, ST7789, SPI 62.5 МГц + ёмкостный тач FT6336U (I2C) | 40–50 FPS, яркие цвета, ~$8–12, мало потребляет, почти не занимает пины | Небольшое разрешение |
| B: 4" HDMI 800×480 (или квадратный 720×720) через mini-HDMI | Большой и чёткий, 60 Гц | +$25–40, толще, +150–250 мА, HDMI-шлейф внутри корпуса |
| C: DPI (параллельный RGB) | 60 Гц, большой | Съедает ~22 GPIO — радиомодулям и пользователю не останется пинов. **Не подходит** |

Драйвер в Linux для A: `panel-mipi-dbi` (DRM, современный) или `fbtft`
(`fb_st7789v`). Интерфейс рисуется через SDL2/LVGL напрямую в DRM —
без X11/рабочего стола, поэтому плавно даже на Pi Zero.

## 4. Распиновка 40 GPIO

Все 40 линий **проходят насквозь** на верхнее гнездо. Колонка «Пользователю»:

- ✅ — свободен, бери для своих проектов;
- 🔶 — общая шина: можно подключать свои устройства на ту же шину
  (I2C с другим адресом, SPI со своим CS);
- ⛔ — занят девайсом; программа не даст его выбрать.

Если нужно больше:

- в настройках можно «отключить» LoRa → освобождаются BCM 18, 22, 23, 27;
- в разделе «Проекты» есть расширитель MCP23017 (I2C, +16 пинов, $1);
- у RP2040 остаются свободные ноги — выводим их на доп. разъём
  «KODY-IO» 2×5 (4 GPIO + 2 АЦП + 3.3 В + GND), Pi управляет ими по USB.

> ⚠️ GPIO Raspberry Pi — **3.3 В**, не более ~16 мА на пин. 5 В на GPIO
> сожгут Pi. На шелкографии рядом с гнездом крупно пишем «3.3V ONLY».

## 5. Радио

| Модуль | Чип | Частоты | Подключение | Антенна |
|---|---|---|---|---|
| Sub-GHz | CC1101 (готовый модуль, напр. E07-M1101D) | 300–348, 387–464, 779–928 МГц | RP2040 | SMA |
| LoRa / Meshtastic | SX1262 (модуль E22-900M22S или E22-400M22S) | 868 / 915 или 433 МГц | Pi SPI1 (работает `meshtasticd` прямо на Linux) | SMA |
| 2.4 ГГц | NRF24L01+ PA/LNA (E01-2G4M27D) | 2.400–2.525 ГГц | RP2040 | SMA |
| SDR | RTL2832U + R828D (как RTL-SDR v4) | 24–1766 МГц (только приём) | USB-хаб | SMA |

- Для v1 **берём готовые экранированные модули** с полуотверстиями — не надо
  разводить ВЧ-тракт самому, и они уже прошли сертификацию у производителя.
- SDR в v1: модуль от RTL-SDR v4 внутри корпуса, подключён к хабу
  через внутренний разъём. Разведение RTL2832U прямо на плате — это v2.
- Wi-Fi и Bluetooth уже есть в Pi Zero W.

## 6. NFC / RFID («как у флиппера, но своя плата»)

- **13.56 МГц**: ST25R3916 — читает и **эмулирует** ISO14443A/B, ISO15693,
  FeliCa. Это та же микросхема, что во Flipper Zero, у ST есть открытая
  библиотека RFAL (C), она запускается на RP2040. Антенна — дорожки на плате
  + согласующая цепь (C, R по даташиту/аппноуту ST AN5276).
- **125 кГц** (EM4100, HID Prox, T5577): без специального чипа —
  PIO RP2040 генерирует 125 кГц → MOSFET-драйвер → LC-контур;
  обратный сигнал → диодный детектор огибающей → компаратор → PIO.
  Эмуляция — нагрузочная модуляция катушки MOSFET-ом.
  Запись в T5577 — тоже есть.

## 7. Питание

| Узел | Чип | Комментарий |
|---|---|---|
| Вход | USB-C (16-pin) + 2× 5.1 кОм на CC1/CC2 | Обычная зарядка 5 В от любого адаптера |
| Заряд + power path | BQ25895 (I2C) | Ток заряда до 3 А, девайс работает во время зарядки |
| Аккумулятор | Li-Po 1S 3000–4000 мА·ч, с платой защиты, NTC | ~4–6 ч работы |
| 5 В для Pi и USB | TPS61088 (boost 5.1 В, до ~3 А) | Включается RP2040 |
| 3.3 В для RP2040/радио | LDO 3.3 В 500 мА от SYS (напр. ME6211/AP2112) | Pi своё 3.3 В делает сам |
| Защита USB-A | AP2553 / TPS2051 (0.5 А на порт) | КЗ на флешке не уронит девайс |
| Уровень заряда | MAX17048 | Проценты в статус-баре |

Бюджет тока (5 В): Pi Zero 2 W до 600 мА, экран 80–120 мА, RTL-SDR ~280 мА,
LoRa TX пик 120 мА, USB-A до 2×500 мА. Пиково ~2.5 А → boost на 3 А с запасом.

> ⚠️ Pi питается через 5 В пины гребёнки (back-powering). Не подключать
> одновременно питание в micro-USB PWR самого Pi. На плате ставим
> идеальный диод (например LM66100) по 5 В.

## 9. План работ в EasyEDA (Pro)

1. **Проект и библиотека.** Создать проект `KODY_mainboard`. Все детали брать
   из библиотеки LCSC/JLCPCB (поиск по названию чипа) — тогда JLCPCB сам
   их запаяет. Отмечать «Basic/Extended part»: Basic дешевле в монтаже.
2. **Схема — по листам** (так легче проверять):
   1. `Power` — USB-C, BQ25895, аккумулятор, TPS61088, LDO, LM66100.
   2. `Pi_Header` — гнездо 2×20 к Pi, сквозная разводка на верхнее гнездо,
      ID EEPROM (24C32 на BCM0/1 — требование стандарта HAT).
   3. `Display` — шлейф экрана, тач, подсветка (MOSFET + PWM).
   4. `USB` — FE1.1s, USB-A ×2, ключи, разъём к RTL-SDR, перемычка к Pi.
   5. `MCU` — RP2040 + флеш + кварц + кнопки, крутилка, вибро, LED.
   6. `RF` — CC1101, SX1262, NRF24 + SMA.
   7. `NFC_RFID_IR` — ST25R3916, 125 кГц, ИК.
   8. `Storage` — microSD №2 (SPI1).
3. **Проверка схемы:** DRC в EasyEDA + сверка с таблицей пинов из раздела 4.
4. **Плата:** 4 слоя (сигнал / сплошная земля / питание / сигнал).
   Сначала расставить механику: экран, крутилка, USB-C, SMA, гнёзда — только
   потом разводить. ВЧ-модули — у края платы, к SMA короткие 50 Ом линии
   (калькулятор импеданса JLCPCB). Под NFC-антенной — без меди.
5. **Заказ:** JLCPCB, 5 шт, монтаж с одной стороны. Крупные детали
   (гнёзда, SMA, аккумулятор) — паять самому.
