## Вертикальная компоновка (v5)

Pi Zero стоит вертикально: гребёнка Pi — вдоль левого края, SD-карта Pi — внизу.

| Сторона | Что там |
|---|---|
| Верх | 3 съёмные антенны SMA (Sub-GHz, LoRa, 2.4 ГГц) + ИК |
| Правый бок | Крутилка под большим пальцем + 3 кнопки |
| Левый бок | 40 GPIO «мамой» (там же, где гребёнка Pi — короткие дорожки) |
| Низ | USB-C быстрая зарядка, USB-C данные, окно SD-карты Pi, индикатор |
| Спереди | Экран 1.9″ 170×320 с тачем — портретный, рамки по бокам ≈ 4 мм |
| Сзади | NFC + 125 кГц снаружи; радио, GPS (антенна у верха — смотрит в небо), RP2040 внутри |

Два способа собрать:

| | А · Пазл | Б · Сэндвич (советую) |
|---|---|---|
| Из чего | 8 плат вокруг Pi | Основная плата (все боковые детали запаяны на заводе) + сменный радио-картридж + корпус |
| Шагов сборки | 8 | 4 |
| Разъёмов между платами | ~10 | 1 |
| Размер с корпусом | ≈ 36 × 71 × 24 мм | ≈ 34 × 70 × 23 мм |
| Аккумулятор | ≈ 1000 мА·ч | ≈ 800 мА·ч |
| Что меняется | любая сторона | радио-картридж целиком (обычный / с LTE и SIM) |

Логика (распиновка, самопроверка плат, одна прошивка на Zero W/2 W) у обоих
вариантов одна. В варианте Б самопроверка видит 3 модуля вместо 7 плат.

# KODY v4 — «пазл» вокруг Raspberry Pi Zero

- **3D-модель (с телефона, есть сборка по шагам):** https://claude.ai/artifact/SPZszNhs2kebLbU7mErjtX
- **Что купить (ссылки на магазины + галочки):** https://claude.ai/artifact/PkMxhhZDHSbbQT44wBgvSS
- Исходники: [`docs/model/kody-model.html`](model/kody-model.html), [`docs/shopping-list.md`](shopping-list.md)

## Главный принцип: сначала Pi в «маму», потом пазл

1. Берёшь Pi Zero WH (гребёнка «папа» вверх).
2. Кладёшь на неё плоский аккумулятор.
3. Втыкаешь Pi в **ядро** — плату размером с Pi, у которой гнездо 2×20 «мама» **внутри, снизу**.
4. Прикручиваешь заднюю плату (радио/NFC/GPS) 4 винтами через отверстия Pi —
   Pi зажата между ядром и задней платой.
5. Защёлкиваешь бока: слева 2 кнопки + окно SD, справа крутилка + кнопка.
6. Ставишь верх (GPIO, SMA, USB-C данные, ИК) и низ (зарядка).
7. Защёлкиваешь экран на ядро.
8. Накручиваешь антенны (или заглушки) и включаешь.

**Как всё «реально взаимодействует и проверяется»:** в каждой части пазла
крошечная память 24C02 с её «паспортом» на общей шине I2C. Ядро несёт
стандартный HAT EEPROM — Pi при загрузке знает, что она в KODY. При включении
программа опрашивает все части и главные микросхемы на них и пишет, что
вставлено, а что нет или неисправно. Код: [`software/kody/panels.py`](../software/kody/panels.py).

```
 ✔ Ядро (гнездо для Pi, гироскоп, вибро)      OK
 ✔ Экран с тачем (спереди)                    OK
 ✘ Крутилка + кнопка (правый бок)             НЕТ
 ! Зарядка + аккумулятор (низ)                ЕСТЬ, НО НЕИСПРАВНА
     └ не отвечает датчик заряда MAX17048 (0x36)
```

## Платы

| Плата | Где | Что на ней |
|---|---|---|
| **Ядро** | над Pi, под экраном | Гнездо 2×20 «мама» для Pi WH, разъёмы по 4 краям, гироскоп LSM6DSO, вибромотор, HAT EEPROM |
| **Экран** | спереди | 1.9″ IPS 170×320 + **ёмкостный тач** CST816 |
| **Левый бок** | слева | 2 кнопки Ø9 мм, окно для SD-карты Pi |
| **Правый бок** | справа | Крутилка (энкодер EC11 с нажатием) + такая же кнопка |
| **Верх** | сверху | 40 GPIO «мамой» (сдвинуто вперёд), 3 гнезда SMA, USB-C данные, ИК |
| **Низ** | снизу | USB-C быстрая зарядка, защита аккумулятора, 5 В для Pi, microSD №2, выключатель |
| **Задняя** | сзади | RP2040, CC1101 + PA, SX1262 (LoRa), NRF24 + PA/LNA, ST25R3916 (NFC), 125 кГц, **GPS** |
| Аккумулятор | между Pi и ядром | Li-Po ≈ 50 × 20 × 7 мм (702050), ≈ 1000 мА·ч |

Питание: аккумулятор → защита + зарядка + повышение до 5 В (нижняя плата) →
ядро → Pi через 5 В пины гребёнки. Верхний USB-C — данные + медленная подзарядка.

## Что реализуется, а что нет

| Хотелка | Вердикт |
|---|---|
| Сначала Pi в «маму» внутри, потом пазл по краям | ✅ |
| Всё связано и само проверяется при включении | ✅ (программа написана) |
| Аккумулятор в «толстом месте», через защиту на Pi | ✅ ≈ 1000 мА·ч, 3–4 часа |
| Тачскрин | ✅ 1.9″ ёмкостный (рамки по бокам ≈ 8 мм) |
| Слева 2 кнопки + SD | ✅ |
| Справа крутилка + кнопка | ✅ (пришли фото ручки — подберу) |
| Гироскоп | ✅ на ядре |
| Вибромотор | ✅ на ядре |
| GPS, скорость | ✅ **сим-карта для GPS не нужна** |
| Сим-карта / мобильный интернет | ⚠️ потом, отдельной сменной задней платой (модем большой и берёт до 2 А) |
| Съёмные антенны SMA + заглушки 50 Ом | ✅ |
| USB-A | ❌ убран — на его месте крутилка |
| Тоньше 22 мм | ❌ толщину задаёт гребёнка Pi WH — зато там аккумулятор |
| Экран без рамок под размер Pi | ⚠️ серийно нет |

## Распиновка (v4)

Радио, NFC, ИК и GPS — на RP2040 задней платы, связь с Pi по UART.
Полная таблица — в [`software/kody/pins.py`](../software/kody/pins.py).

| Занято | BCM |
|---|---|
| Экран SPI0 + D/C, RESET, подсветка | 8, 10, 11 (+9), 24, 25, 13 |
| I2C: тач, гироскоп, зарядка, EEPROM плат (общая шина) | 2, 3 |
| Прерывание тача | 4 |
| Кнопки B1, B2 (слева), B3 (справа) | 5, 6, 16 |
| Крутилка A / B | 17, 27 |
| Вибромотор | 12 |
| UART ↔ RP2040 | 14, 15 |
| RP2040 BOOTSEL / RUN | 22, 23 |
| HAT EEPROM ядра | 0, 1 |
| **Свободно для своих проектов** | **7, 18, 19, 20, 21, 26** + шины I2C и SPI0 |

## Одна прошивка на Zero WH и Zero 2 W

Raspberry Pi OS Lite **32-bit** грузится на обеих, `software/kody/board.py`
сам узнаёт плату и выбирает режим.
