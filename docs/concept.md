# KODY v2 — «пазл» вокруг Raspberry Pi Zero

**3D-модель (открывается с телефона):** https://claude.ai/artifact/SPZszNhs2kebLbU7mErjtX
Исходник модели: [`docs/model/kody-model.html`](model/kody-model.html).

## Идея

Никакой большой платы. Шесть маленьких плат обнимают Pi Zero W со всех сторон,
отпечаток почти как у самой Pi: **≈ 69 × 34 мм, толщина ≈ 22 мм** без корпуса.
Вставил Pi в «хребет» — и всё заработало.

```
              ┌──────── ХРЕБЕТ + GPIO 2×20 (сверху) + ИК ────────┐
   КНОПКИ  ┌──┤                                                  ├──┐  СЕНСОР
  (левый   │B1│              ЭКРАН 1.9″ 170×320 (спереди)        │▒▒│  слайдер
   бок)    │B2│                                                  │▒▒│  (правый бок)
           └──┤                                                  ├──┘
              └──── ПИТАНИЕ: USB-C · microSD №2 · выкл (снизу) ──┘
                  сзади: РАДИО + NFC (CC1101, LoRa, NRF24, ST25R3916, 125 кГц, RP2040)
```

## Платы

| Плата | Где | Что на ней | Как подключена |
|---|---|---|---|
| **Хребет + GPIO** | верхний торец | Угловое гнездо, в которое втыкается Pi WH; все 40 GPIO наружу низким гнездом 2×20; ИК-диод и приёмник; EEPROM | Pi вставляется сюда; остальные платы стыкуются к хребту |
| **Экран** | спереди | 1.9″ IPS 170×320 (ST7789, SPI) + ёмкостный тач (CST816, I2C) | разъём 1.27 мм к хребту |
| **Кнопки** | левый бок | 2 кнопки Ø9 мм, окно для SD-карты Pi | шипы-пазы + разъём 1.27 мм |
| **Сенсор** | правый бок | Ёмкостный слайдер 22 мм (как Camera Control), нажатие, вибромотор | шипы-пазы + разъём 1.27 мм |
| **Питание** | нижний торец | USB-C (зарядка + внешний SDR/флешки), зарядка Li-Po + 5 В, microSD №2, выключатель | разъём 1.27 мм |
| **Радио + NFC** | сзади | RP2040, CC1101, SX1262 (LoRa), NRF24, ST25R3916 (NFC чтение + эмуляция), катушка 125 кГц, 3× MMCX | pogo-контакты к низу Pi: USB (PP22/PP23) и питание, плюс к пайке гребёнки |
| Аккумулятор | внутри | Li-Po ≈ 4.5 × 20 × 50 мм, 500–700 мА·ч | лежит между Pi и экраном, рядом с гребёнкой |

Как соединяются платы между собой: **шипы и пазы** по краям (механика, как пазл)
+ маленькие **угловые разъёмы 1.27 мм** (сигналы и питание) + 2 винта M2
через хребет. Разобрать можно без паяльника.

## Что можно и что нельзя

| Хотелка | Вердикт | Как сделаем |
|---|---|---|
| Не больше Pi Zero | ✅ | ≈ 69 × 34 мм (боковые платы +2 мм с каждой стороны). Толщину ≈ 22 мм задаёт гребёнка Pi WH |
| Вставил — заработало | ✅ | Pi в хребет; задняя плата берёт USB и питание pogo-контактами снизу Pi |
| Тачскрин, много герц | ⚠️ | Экрана ровно 65 × 30 серийно нет. 1.9″ 170×320: 30–50 FPS даже на Zero W, рамки по бокам ≈ 8 мм. «Без рамок» — заказной экран при партии |
| Кнопки сбоку | ✅ | 2 штуки на левой плате |
| Сенсор «как у Apple» | ✅ | Слайдер дорожками на плате + нажатие + вибро |
| GPIO сверху «мамой» | ✅ | Все 40, свободно для своих проектов **10 пинов** (BCM 7, 14–21, 26) + шины I2C/SPI |
| CC1101, LoRa, NRF24 | ✅ | На задней плате, антенны через MMCX |
| Своя плата NFC + 125 кГц | ✅ | ST25R3916 + катушки на внешней стороне задней платы |
| ИК | ✅ | На торце хребта |
| microSD №2 | ✅ | На нижней плате |
| SDR внутри | ❌ v1 | RTL-SDR больше самой Pi. v1 — внешний SDR в USB-C, v2 — чип SDR на задней плате |
| USB-A «квадратный» | ❌ | 14 мм в глубину при ширине 30 мм — не влезает. USB-C + переходник |
| Большие SMA-антенны | ⚠️ | MMCX + короткие антенны |
| Батарея | ⚠️ | 500–700 мА·ч ≈ 1.5–3 часа |
| Механическая крутилка | ⚠️ | Заменена сенсором; можно поставить мини-колёсико вместо одной кнопки |

## Одна прошивка на Zero WH и Zero 2 W

- Ставим **Raspberry Pi OS Lite 32-bit** — грузится на обеих платах.
- `software/kody/board.py` читает модель платы и выбирает режим: Zero W —
  интерфейс 30 FPS, без «водопада» SDR; Zero 2 W — 50 FPS, всё включено.
- Гребёнка одинаковая — пазл подходит к обеим без переделок.

## Распиновка (v2)

Всё радио, NFC и ИК живут на RP2040 задней платы и общаются с Pi по USB,
поэтому Pi почти не тратит GPIO. Полная таблица — в
[`software/kody/pins.py`](../software/kody/pins.py).

| Занято | BCM |
|---|---|
| Экран SPI0 + D/C, RESET, подсветка | 8, 10, 11 (+9), 24, 25, 13 |
| I2C (тач, слайдер, батарея) — общая шина | 2, 3 |
| Прерывания тача / слайдера | 4, 27 |
| Кнопки B1, B2 | 5, 6 |
| Вибромотор | 12 |
| RP2040 BOOTSEL / RUN | 22, 23 |
| HAT EEPROM | 0, 1 |
| **Свободно** | **7, 14, 15, 16, 17, 18, 19, 20, 21, 26** |

## Дальше

1. Ты смотришь модель и правишь: что куда переставить, размеры, цвета.
2. Покупаем модули для макетки ([список](shopping-list.md)) и собираем всё на проводах.
3. Рисуем в EasyEDA по одной плате, начиная с **хребта** (он самый простой и
   на нём проверяется посадка Pi), потом экран, потом задняя плата.
