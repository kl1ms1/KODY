# KODY v3 — «пазл» вокруг Raspberry Pi Zero

**3D-модель (открывается с телефона):** https://claude.ai/artifact/SPZszNhs2kebLbU7mErjtX
Исходник модели: [`docs/model/kody-model.html`](model/kody-model.html).

## Что поменялось в v3

- **SDR убран.** Вместо него три мощные антенны: Sub-GHz 433 (CC1101 + усилитель),
  LoRa 868 (SX1262), 2.4 ГГц (NRF24 + PA/LNA).
- **Антенны сверху**, рядом с GPIO. Гребёнка GPIO сдвинута к переднему краю,
  антенны стоят за ней у заднего края. В одну линию с гребёнкой (51 мм) три SMA
  при ширине 69 мм не помещаются, а «в два ряда по глубине» — помещаются.
- **Заглушки вместо антенн:** нагрузка SMA 50 Ом. Если антенну не ставишь —
  накручиваешь заглушку, и усилитель не сгорит при случайной передаче.
- **USB-A вернулся** — в правый бок, над Pi, в зазоре гребёнки. За это
  аккумулятор стал короче (≈ 450 мА·ч).
- **Две зарядки:** снизу USB-C — быстрая зарядка с защитой аккумулятора;
  сверху USB-C — данные (компьютер видит KODY) и медленная зарядка до 0.5 А.
- **Сенсор убран**, вместо него — список идей (ниже).

## Платы

| Плата | Где | Что на ней |
|---|---|---|
| **Верх: GPIO + антенны** | верхний торец | Pi вставляется сюда; 40 GPIO наружу (сдвинуто вперёд); USB-C для данных; 3 гнезда SMA; ИК-диод и приёмник |
| **Экран** | спереди | 1.9″ IPS 170×320 (ST7789, SPI) + ёмкостный тач (CST816) |
| **Кнопки** | левый бок | 2 кнопки Ø9 мм, окно для SD-карты Pi |
| **USB-A + идея** | правый бок | USB-A без переходников + окно ≈ 14 × 18 мм под идею |
| **Низ: быстрая зарядка** | нижний торец | USB-C (только зарядка), BQ25895 + защита DW01A, microSD №2, выключатель, индикатор |
| **Радио + NFC** | сзади | RP2040, E07-433M20S, E22-900M22S, NRF24 PA/LNA, ST25R3916 (NFC), катушка 125 кГц, USB-хаб + коммутатор |
| Аккумулятор | внутри | Li-Po ≈ 42 × 18 × 4.5 мм, ≈ 450 мА·ч |

## Три USB

| Порт | Зачем | Ток |
|---|---|---|
| Снизу USB-C | Только зарядка: быстро (≈ 1C, полный заряд ≈ 1 ч) + защита от перезаряда, переразряда, КЗ, перегрева | до ~1 А в аккумулятор + питание девайса |
| Сверху USB-C | Данные: KODY видна компьютеру как флешка / сеть / COM-порт. Медленная подзарядка | до 0.5 А |
| Справа USB-A | Флешки, клавиатура, внешние модули (в т.ч. SDR, если понадобится) | отдаёт до 0.5 А |

У Pi Zero один USB. Чип-коммутатор переключает его: подключён компьютер
сверху — Pi работает как «гаджет»; не подключён — Pi работает как хост через
хаб (USB-A + RP2040 с радио). Быстрая зарядка при маленьком аккумуляторе — это
≈ 1 А: больше аккумулятору на 450 мА·ч вредно, поэтому 9–12 В (PD) не нужны.

## Мощность радио

Модули с усилителем: CC1101 + PA до 100 мВт, SX1262 до 160 мВт, NRF24 + PA
до 500 мВт. Без лицензии разрешено меньше: 433 МГц ≈ 10 мВт, 868 МГц ≈ 25 мВт,
2.4 ГГц ≈ 100 мВт. Прошивка по умолчанию держит разрешённую мощность, «турбо»
включается вручную — ответственность на владельце. Важно и для продажи.

## Что можно и что нельзя

| Хотелка | Вердикт |
|---|---|
| Размер не больше Pi Zero (в плане) | ✅ ≈ 69 × 34 мм, толщина ≈ 22 мм, плюс антенны сверху |
| 3 антенны сверху + GPIO | ✅ в два ряда по глубине (в одну линию не влезает) |
| Заглушки вместо антенн | ✅ нагрузки 50 Ом |
| USB-A без переходников | ✅ правый бок, аккумулятор меньше |
| Быстрая зарядка снизу с защитой | ✅ |
| Данные + медленная зарядка сверху | ✅ |
| Экран без рамок во весь фасад | ⚠️ серийно нет; 1.9″ с рамками ≈ 8 мм по бокам |
| Аккумулятор | ⚠️ ≈ 450 мА·ч → 1–2 часа активной работы |

## Идеи для правого бока (вместо сенсора)

Окно ≈ 14 × 18 мм рядом с USB-A:

1. **Мини-джойстик на 5 направлений** — как крестовина у Flipper. *Советую.*
2. **Колёсико прокрутки** как у мышки — быстро листать списки и частоты. *Советую.*
3. RGB-светодиод состояния (приём / передача / зарядка).
4. Фонарик + УФ-светодиод (проверка купюр и меток).
5. Лазерный дальномер VL53L1X (до 4 м).
6. Датчик погоды BME280 (температура, влажность, давление).
7. Маленький сканер отпечатка пальца — блокировка девайса.
8. Магнитный разъём с pogo-контактами для внешних модулей.

## Одна прошивка на Zero WH и Zero 2 W

Raspberry Pi OS Lite **32-bit** грузится на обеих. `software/kody/board.py`
сам узнаёт плату и выбирает режим (Zero W — 30 FPS, Zero 2 W — 50 FPS).
