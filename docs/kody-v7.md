# KODY v7 — финальная компоновка «Сэндвич»

**3D-модель (сборка по шагам + просмотр каждой платы):** https://claude.ai/artifact/SPZszNhs2kebLbU7mErjtX

Вертикальный, как телефон. Две свои платы + Raspberry Pi Zero WH + экран +
аккумулятор + корпус. **Никаких проводов** — только гнёзда, защёлки,
подпружиненные контакты и пайка «деталь в плату».

Габарит ≈ **36 × 72 × 30 мм** (с бампером).

```
 спина ─┬─ Корпус: задняя часть (жёсткий пластик) + резиновый бампер
        ├─ ЗАДНЯЯ ПЛАТА: радио, NFC/RFID, GPS, USB-хаб, 4 гнезда SMA сверху
        │     ↑ pogo-контакты упираются в площадки снизу Pi (USB + питание)
        ├─ Raspberry Pi Zero WH
        │     ↓ гребёнка Pi входит в гнездо «мама» на передней плате
        ├─ ПЕРЕДНЯЯ ПЛАТА: питание UPS, кнопки, крутилка, датчики, GPIO наружу, вход HDMI
        ├─ Аккумулятор (лепестки припаяны к передней плате)
        ├─ Экран с тачем и стеклом (одним модулем, приклеен к рамке)
 лицо ──┴─ Корпус: передняя рамка с уплотнителем
```

---

## Плата 1 — ПЕРЕДНЯЯ («питание, экран, управление»)

Всё, что ты хотел в одной плате: защита аккумулятора, UPS, гироскоп и прочее.

| Блок | Что стоит | Что делает |
|---|---|---|
| Гнездо для Pi | 2×20 «мама», снизу платы | Pi WH втыкается — готово |
| **Питание как UPS-Lite** | BQ25895 + защита DW01A/FS8205A + MAX17048 + повышайка 5 В | Зарядка, power-path (воткнул/выдернул — Pi не моргнёт), защита от перезаряда/переразряда/КЗ/перегрева, проценты, аккуратное выключение при 3 % |
| Аккумулятор | Li-Po ≈ 26 × 50 × 5–6 мм, ≈ 900–1000 мА·ч, **лепестки без проводов** | Паяется прямо на площадки платы, 3 точки |
| Мозг питания и кнопок | STM32G0 (маленький микроконтроллер) | Всегда включён: кнопка питания, 3 кнопки, крутилка, вибро, подсветка; с Pi говорит по общей шине I2C |
| Датчики | Гироскоп LSM6DSV16X, датчик света VEML7700, часы RV-3028 | Автоповорот, автояркость, время без интернета |
| Вибро | DRV2605L + линейный моторчик LRA | Чёткие «щелчки» как в iPhone |
| Экран | Мост **HDMI → MIPI** (Lontium LT6911) + разъём экрана с защёлкой | Картинка с Pi по HDMI, 60 Гц, ни одного GPIO |
| Звук | Усилитель MAX98357A + динамик | Звук идёт по тому же HDMI |
| Правый бок | Кнопка, кнопка, **крутилка**, кнопка — **по центру бока** | Управление |
| Левый бок | Гнездо GPIO 2×20 «мама» + защита от статики | **Все 40 пинов Pi наружу** |
| Низ | USB-C (водозащищённый) | Быстрая зарядка |

## Плата 2 — ЗАДНЯЯ («радио и связь»)

| Блок | Что стоит | Что делает |
|---|---|---|
| Связь с Pi | Pogo-контакты на площадки снизу Pi: USB D+/D−, 5 В, GND | Без шлейфов и проводов |
| USB-хаб | USB2514B | Делит единственный USB Pi на всех |
| Мозг радио | **RP2350** (48 ног) | Управляет всеми радиочипами в реальном времени |
| **«Рация» 433 / UHF** | **BK4819** — тот же чип, что в рациях Quansheng UV-K5 | Голос FM/AM на каналах LPD/PMR 433–446 МГц, приём 18–660 и 840–1300 МГц (сюда входят «800-е» каналы) |
| Пульты 433 (как Flipper) | CC1101 на той же антенне через переключатель | Шлагбаумы, ворота, датчики — запись/повтор своих |
| **LoRa** | SX1262 (22 dBm) или «полевой» 1 Вт модуль | Чат и координаты на 5–15 км в поле, совместим с Meshtastic |
| 2.4 ГГц | NRF24L01+ PA/LNA | Мыши, клавиатуры, дроны на 2.4 ГГц |
| Wi-Fi / Bluetooth | **ESP32-C5** (2.4 + 5 ГГц, BLE) | Все Wi-Fi/BT-инструменты; встроенный Wi-Fi Pi — только интернет, не «тупит» |
| GPS | u-blox MAX-M10S | Скорость, координаты, точное время |
| NFC 13.56 МГц | **ST25R3916** + катушка дорожками на плате + ферритовая плёнка | Чтение и эмуляция (как Flipper) |
| RFID 125 кГц | Схема на RP2350 + катушка | Домофонные ключи EM4100 / T5577 |
| ИК | Светодиод + приёмник | Пульты ТВ/кондиционеров |
| Микрофон | USB-аудиочип + микрофон | Голос для рации и заметок |
| Низ | USB-C (водозащищённый) | Флешки, клавиатура, внешний SDR |
| **Верх: 4 гнезда SMA** | LoRa · Рация 433 · 2.4 ГГц · GPS | Антенны съёмные, вместо них — заглушки 50 Ом |

**Почему 4 антенны:** LoRa, рация (433/UHF), 2.4 ГГц, GPS — у каждого радио
своя частота и своя антенна. Wi-Fi у ESP32-C5 — встроенная антенна на плате
(пятое гнездо по желанию).

## Кто что паяет

**Завод (JLCPCB) паяет ВСЁ, включая гнёзда.** У них есть монтаж выводных
деталей (THT), поэтому гнездо для Pi на 40 ножек, гнездо GPIO, кнопки,
крутилку, USB-C и SMA тоже впаяет завод. Платы приходят готовыми.

**Ты паяешь только 3 точки** — лепестки аккумулятора (+, −, датчик
температуры). И то можно попросить завод.

Чтобы **все 40 пинов работали** — завод после пайки делает визуальную
проверку (AOI), а мы при первом включении запускаем самопроверку KODY,
которая прозванивает каждый GPIO через тестовую заглушку (кольцо пин→пин).

## Все 40 пинов — твои

KODY не занимает GPIO вообще:
- экран — через HDMI;
- кнопки, крутилка, питание, датчики — через свой микроконтроллер на общей
  шине I2C (пины 3/5 — к ней можно подключать и свои устройства);
- радио, NFC, GPS, Wi-Fi — через USB.

Итог: **26 GPIO полностью свободны** + I2C общая + питание 3.3/5 В + GND.
Пины 27/28 — «паспорт» платы (так требует стандарт HAT). На гнезде стоит
защита от статики и предохранитель на 5 В/3.3 В — пины не сгорят от
случайного касания.

## Экран

Чтобы было 60 кадров, хорошие цвета и плавный тач, берём **экран от
смартфона/часов**, а не модуль «для Arduino»:

| Что | Требование |
|---|---|
| Размер | ≈ 2.4–2.6″, ширина под корпус 34 мм, рамки ≈ 1.5–2 мм по бокам |
| Матрица | IPS или AMOLED, разрешение от ≈ 360×720 |
| Частота | 60 Гц (через HDMI, Pi Zero выдаёт это без нагрузки на GPIO) |
| Подключение | MIPI DSI (через мост HDMI→MIPI на передней плате) |
| Тач | Ёмкостный контроллер Goodix GT9xx / FocalTech, опрос **120 Гц** — линия рисуется плавно, как на телефоне, а не точками |
| Глаза | **Без мерцания**: IPS с DC-подсветкой или AMOLED с высокочастотным ШИМ; автояркость + «тёплый» ночной режим |
| Стекло | Закалённое стекло, приклеенное к матрице на заводе (ламинация, как у телефонов) |

Плавность анимаций: экран всегда 60 Гц; интерфейс 60 кадров/с — на Zero 2 W,
на Zero W тяжёлые экраны ≈ 30–40 кадров/с.

### Как крепится экран

Как в телефоне:
1. Экран (матрица + тач + стекло — один готовый модуль) вклеивается в
   переднюю рамку корпуса на рамочный скотч (не жидкий клей).
2. Его родной шлейф загибается и защёлкивается в разъём на передней плате.
3. Под экраном — поролоновая прокладка, она прижимает аккумулятор и гасит удары.
4. Рамка защёлкивается на заднюю часть корпуса и прижимается 4 винтами.

Экран не держится на проводах и не висит на шлейфе.

### Как картинка попадает на экран

У Pi Zero есть mini-HDMI. В него вставляется короткий гибкий переходник
**mini-HDMI → шлейф** (готовая деталь, просто вставить), шлейф защёлкивается
на переднюю плату. Паять ничего не нужно.

## Удары и вода

| Что | Как |
|---|---|
| Корпус | Жёсткий нейлон PA12 (печать SLS на заводе) + **резиновый бампер TPU** на углах и рёбрах |
| Экран | Стекло утоплено на 0.5 мм ниже края рамки — при падении экраном вниз удар принимает рамка |
| Внутри | Поролон между слоями, аккумулятор приклеен, платы прижаты винтами через стойки |
| Pi | Зажата между двумя платами 4 винтами — не выскочит из гнезда |
| Вода | Уплотнитель по шву корпуса, водозащищённые USB-C, мембраны на кнопках, кольца на SMA, **лак на платах** |
| GPIO | Резиновая заглушка на гнездо |
| Итог | **IP54**: снег, брызги, пыль, падение с 1.5 м. Не для плавания |

Падение на попу в заднем кармане: корпус из PA12 + бампер выдерживает
изгиб, а платы короткие и зажаты — им некуда гнуться.

## Сборка по шагам (то, что будешь делать ты)

1. Платы пришли с завода — всё уже впаяно.
2. Припаяй 3 лепестка аккумулятора к передней плате, наклей его на каптон.
3. Вставь переходник mini-HDMI в Pi.
4. Положи заднюю плату в заднюю часть корпуса.
5. Поставь Pi на заднюю плату: отверстия — на стойки, pogo-контакты сами упрутся в площадки.
6. Надень переднюю плату на Pi: гребёнка в гнездо, нажать до щелчка; шлейф HDMI — в разъём.
7. Закрути 4 винта насквозь.
8. Вклей экран в переднюю рамку, шлейф экрана — в разъём передней платы.
9. Закрой рамку, 4 винта, надень бампер.
10. Накрути антенны (или заглушки), включи — KODY проверит всё сама.

## Своя NFC/RFID вместо PN532

См. предыдущее описание в [`docs/boards.md`](boards.md): ST25R3916 (как во
Flipper) для 13.56 МГц с эмуляцией, 125 кГц на RP2350, файлы в формате Flipper.
Порядок: макетка с готовой платой ST → макетка 125 кГц → катушка на нашей
плате + подстройка NanoVNA → схема в EasyEDA → прошивка.
