# KODY «Сэндвич» — что на каждой плате, кто паяет и как это работает

**3D-модель:** https://claude.ai/artifact/SPZszNhs2kebLbU7mErjtX ·
**Покупки:** https://claude.ai/artifact/PkMxhhZDHSbbQT44wBgvSS

## Слои снизу вверх (со спины к экрану)

```
 спина ─┬─ Корпус: задняя крышка (3D-печать)
        ├─ Радио-картридж: NFC/125 кГц-катушки снаружи, ферритовый лист, модули внутри   ~4 мм
        ├─ Аккумулятор плоский 50 × 30 × 5 мм, на изолирующей прокладке            ~5 мм
        ├─ Raspberry Pi Zero W / WH (2 W)                                          ~3 мм
        ├─ «Толстое место» 11 мм (гребёнка): питание UPS + ESP32 + приколы
        ├─ Основная плата: гнездо Pi снизу, все боковые детали по краям             ~1.6 мм
        ├─ Экран 1.9″ с тачем                                                      ~3 мм
 лицо ──┴─ Корпус: передняя рамка
```

Габарит с корпусом ≈ **34 × 70 × 29 мм** (было 23 — добавилось 6 мм на
большой плоский аккумулятор). В плане — размер Pi плюс стенки корпуса.

## 1. Основная плата (главная)

| Что на ней | Зачем |
|---|---|
| Гнездо 2×20 «мама» снизу | Pi WH втыкается сюда — и всё |
| HAT EEPROM 24C32 | Pi при загрузке знает, что она в KODY, и сама включает экран, кнопки, датчики |
| **Блок питания UPS** (снизу, в «толстом месте») | см. раздел «Питание» |
| Гироскоп **LSM6DSV16X** | Автоповорот экрана, жесты, шагомер. Внутри свой «мозг» (sensor fusion) — считает положение сам и не грузит Pi |
| Компас **LIS2MDL** | Стрелка на север, азимут для антенн |
| Датчик света **VEML7700** | Автояркость экрана, как у телефона (смотрит через окошко в рамке) |
| Вибро **DRV2605L + LRA-моторчик** | Чёткие «щелчки» как в iPhone, а не жужжание: щелчок на каждый шаг крутилки, разные эффекты |
| Часы **RV-3028** | Время идёт даже при выключенной Pi и без интернета (берёт микроамперы) |
| **ESP32-C5** (в «толстом месте») | Отдельный Wi-Fi 2.4 + 5 ГГц и Bluetooth для инструментов — см. «Wi-Fi» |
| Справа: крутилка EC11 + 3 кнопки (угловые) | Управление |
| Слева: полоска GPIO 2×20, припаяна под 90° | Свои проекты |
| Снизу: 2× USB-C, индикатор заряда | Зарядка / данные |
| Шлейф к экрану, шлейф к радио-картриджу | Связь с остальными |

**Кто паяет:** вся мелочь (чипы, резисторы, конденсаторы) — завод
(JLCPCB, монтаж SMT). Сами паяем только крупное: гнёзда 2×20, крутилку,
полоску GPIO, провода аккумулятора. Это ~20 минут паяльником.

## 2. Питание «как UPS-Lite» (часть основной платы)

```
 USB-C снизу (быстро) ──┐
                        ├─► BQ25895 ──► SYS ──► повышайка 5.1 В ──► Pi (5 В пины) + всё остальное
 USB-C сверху (медл.) ──┘   (зарядка,          (TPS61088)
                            power-path)
                               │
                       аккумулятор Li-Po ◄── защита DW01A + FS8205A ◄── NTC (датчик t° на аккумуляторе)
                               │
                          MAX17048 (проценты заряда)
```

| Функция | Как сделано |
|---|---|
| Работа от сети и от батареи **без перезагрузки** | Power-path в BQ25895: воткнул/выдернул зарядку — Pi не моргнула (это и есть «UPS») |
| Быстрая зарядка | Снизу до ~1.5 А в аккумулятор (≈ 1C), полный заряд ≈ 50–60 мин |
| Медленная через верхний USB-C | Ограничение 0.5 А, чтобы не перегружать порт компьютера |
| Защита от перезаряда / переразряда / КЗ | Отдельная схема DW01A + ключи FS8205A прямо у аккумулятора — дублирует защиту зарядки |
| Защита от перегрева | NTC-термистор приклеен к аккумулятору: горячо или холодно — зарядка стоп |
| Аккуратное выключение | При 3 % Pi получает сигнал и выключается сама, файлы не бьются |
| Кнопка питания | Долгое нажатие на кнопку крутилки — вкл/выкл |
| Проценты и время работы | MAX17048 — в статус-баре |

**Аккумулятор:** плоский Li-Po **503050** (5 × 30 × 50 мм, ≈ 1000–1100 мА·ч),
припаивается проводами к основной плате (3 провода: +, −, NTC). Ровно в
ширину Pi, по длине — между крепёжными отверстиями. Под ним каптоновая
плёнка, чтобы пайка Pi не проколола оболочку. ≈ **4–5 часов** работы
(Zero W), ≈ 2.5–3 часа (Zero 2 W).

## 3. Радио-картридж (сзади, сменный)

| Что на нём | Зачем |
|---|---|
| **RP2040** | Управляет всем радио в реальном времени, с Pi говорит по UART |
| **CC1101 + усилитель** (E07-433M20S) | Sub-GHz 433 МГц: пульты, шлагбаумы, датчики |
| **SX1262** (E22-900M22S) | LoRa 868 МГц: связь на километры, Meshtastic |
| **NRF24L01+ PA/LNA** | 2.4 ГГц: беспроводные мыши, клавиатуры, дроны |
| **ST25R3916** + катушка | NFC 13.56 МГц: чтение и эмуляция |
| Схема 125 кГц + катушка | Домофонные ключи EM4100 / T5577 |
| **GPS** u-blox MAX-M10S + антенна | Скорость, координаты, время. Антенна у верхнего края — в небо |
| 3 гнезда SMA на верхнем торце | Съёмные антенны или заглушки 50 Ом |
| Ферритовый лист между катушками и аккумулятором | Без него металл аккумулятора «глушит» NFC (в телефонах так же) |
| ИК-светодиод и приёмник | Пульты ТВ/кондиционеров |

**Кто паяет:** завод (SMT), сами — только гнёзда SMA и катушка 125 кГц.
Подключение к основной плате — один шлейф FPC вокруг нижнего края Pi.

## 4. Экран

1.9″ IPS 170×320, ST7789 + ёмкостный тач CST816, шлейф к основной плате.
Готовый модуль — не паяем. Автоповорот по гироскопу, автояркость по датчику
света.

Можно лучше: **AMOLED 1.91″ 240×536** (чёрный как в телефоне, очень яркий).
Минус: Pi Zero гонит его по обычному SPI медленнее — ≈ 25–30 кадров/с
против 40–50 у IPS. Предлагаю IPS в v1 и AMOLED как опцию, когда проверим
на макетке.

## Дальность антенн («как у рации, до 2 км»)

Дальность зависит от трёх вещей: мощность, антенна, прямая видимость. Под
«2 км» берём антенны как у раций — полуволновые / 3–5 dBi, а не «пимпочки».

| Радио | Мощность | Антенна | Прямая видимость | Город |
|---|---|---|---|---|
| **LoRa 868** (SX1262) | 25 мВт (по закону) … 160 мВт | 868 МГц, 5 dBi, ~20 см | **5–15 км** | 1–3 км |
| **Sub-GHz 433** (CC1101 + PA) | 10 мВт (по закону) … 100 мВт | 433 МГц, «как у рации» (Nagoya NA-771 SMA-M, ~40 см) | 0.5–1 км при 10 мВт, **1.5–2 км** при 100 мВт | 200–500 м |
| **2.4 ГГц** (NRF24 PA/LNA) | до 100 мВт | 2.4 ГГц, 5 dBi | 0.8–1 км | 100–300 м |

- **LoRa** легко бьёт 2 км даже по закону — у неё огромная чувствительность.
  «Поделать с LoRa»: настройки скорость/дальность (SF7…SF12), совместимость
  с Meshtastic, подбор антенны. Есть вариант модуля на 1 Вт (E22-900M30S) —
  до 20+ км, но он крупнее и берёт ~1 А, это отдельный «дальнобойный» картридж.
- **433 МГц на 2 км** — только с антенной «как у рации» и мощностью выше
  разрешённой без лицензии (в РФ для 433 МГц — 10 мВт). Прошивка по
  умолчанию держит закон, «турбо» включает владелец.
- Гнёзда на KODY — **SMA-female** (дырка). Антенны берём **SMA-male**
  (штырёк). Антенны для Baofeng обычно SMA-female — на KODY не встанут,
  бери версию «SMA-M».

## Wi-Fi и Bluetooth — без капризов

Почему Wi-Fi «тупил» на Pwnagotchi: он переводит встроенный Wi-Fi Pi в
режим мониторинга (сниффинг) с патчами nexmon. В этом режиме чип не может
нормально подключаться к сети и часто падает. Это ограничение чипа Pi,
а не баг конкретной сборки.

Как сделаем у себя:

1. **Встроенный Wi-Fi Pi — только для интернета.** Никаких патчей, обычный
   NetworkManager. Подключение по QR-коду / с экрана, автопереподключение,
   сторож «нет сети 30 с → перезапуск Wi-Fi».
2. **Все Wi-Fi/BT-инструменты — на отдельном ESP32-C5** (2.4 + 5 ГГц,
   Bluetooth LE). Сканер сетей и устройств, анализатор каналов, BLE-трекеры
   — работают, а интернет на Pi при этом не отваливается.
3. Нельзя (закон): глушить чужие сети, отключать чужих клиентов (deauth),
   перехватывать чужие пароли. В прошивке этого не будет.

## Ещё приколы, которые влезут в «толстое место»

1. **Динамик + микрофон** (I2S): звуки интерфейса, голосовые заметки, рация «нажми и говори» через LoRa-сеть.
2. **Ультрафиолетовый светодиод + фонарик** на верхнем торце.
3. **Барометр BMP390** — высота с точностью до этажа, погода.
4. **Лазерный дальномер VL53L4CD** — рулетка до 1.3 м.
5. **Режим «маячок»**: GPS + LoRa — шлёт координаты на второй KODY в 5–10 км.
6. **Компас для антенны**: показывает, куда направить антенну на источник сигнала (по уровню сигнала + компасу).
