Wi-Fi без капризов

Встроенный Wi-Fi Pi работает только для интернета: обычный режим, автопереподключение, сторож. Все Wi-Fi/Bluetooth-инструменты — на отдельном чипе ESP32-C5 (2.4 + 5 ГГц), поэтому интернет не отваливается, как на Pwnagotchi.
