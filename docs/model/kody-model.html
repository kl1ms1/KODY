KODY: пазл вокруг Pi Zero

Шесть маленьких плат обнимают Raspberry Pi Zero W со всех сторон. Вставил Pi в «хребет» — спереди экран, по бокам кнопки и сенсор, сверху GPIO, сзади радио и NFC. Размеры примерные, ±1–2 мм.

Отпечаток не больше Pi ZeroМОЖНОБоковые платы добавляют ~2 мм с каждой стороны: ≈ 69 × 34 мм. Толщина ≈ 22 мм — её задаёт гребёнка Pi WH (11 мм между платами).
Вставил Pi — и всё заработалоМОЖНОPi вставляется в «хребет». Задняя плата берёт USB и питание подпружиненными контактами (pogo) снизу Pi — без проводов.
Тачскрин, много герцКОМПРОМИСССерийного экрана ровно 65 × 30 нет. Берём 1.9″ IPS 170 × 320 с ёмкостным тачем: 30–50 FPS даже на Zero W. Рамки по бокам ≈ 8 мм. «Без рамок» — только заказной экран на партию.
Кнопки сбоку, большиеМОЖНОДве кнопки Ø9 мм с мягким ходом на левой плате.
Сенсор «как у Apple» сбокуМОЖНОЁмкостный слайдер дорожками прямо на плате + нажатие + вибромотор для «щелчков».
GPIO сверху «мамой»МОЖНОВсе 40 пинов выходят на низкое гнездо 2×20 на верхнем торце.
CC1101, LoRa, NRF24 сзадиМОЖНОМодули на задней плате, антенны — маленькие разъёмы MMCX (как SMA, только в 3 раза меньше).
Своя плата NFC + RFID 125 кГцМОЖНОST25R3916 (чтение + эмуляция) и катушки прямо на внешней стороне задней платы.
ИКМОЖНОИК-светодиод и приёмник на торце «хребта».
Второй слот microSDМОЖНОНа нижней плате, рядом с USB-C.
SDR внутриНЕ ВЛЕЗЕТ (v1)Донгл RTL-SDR сам больше Pi. В v1 — внешний SDR в USB-C. В v2 можно развести чип SDR на задней плате — это самая сложная часть.
USB-A «квадратный»НЕ ВЛЕЗЕТОн 14 мм в глубину при ширине устройства 30 мм. Вместо него USB-C, переходник USB-C → USB-A в комплекте.
Большие антенны SMAКОМПРОМИССMMCX + короткие антенны. Одну SMA можно оставить для Sub-GHz.
БатареяКОМПРОМИССПомещается ~500–800 мА·ч (лежит между Pi и экраном) — это 1.5–3 часа работы.
Механическая крутилкаЗАМЕНЕНАВместо неё сенсорный слайдер. Можно поставить маленькое колёсико на место одной из кнопок.

Одна прошивка для Zero W / WH и Zero 2 W: программа сама узнаёт плату и включает подходящий режим. Гребёнка у них одинаковая, пазл подходит к обеим.
