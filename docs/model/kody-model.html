KODY: пазл вокруг Pi Zero

Версия 4. Сначала Pi Zero WH втыкается в ядро — плату с гнездом «мама» внутри. Потом по краям защёлкиваются остальные части пазла, и при включении KODY сама проверяет, что всё на месте. В «толстом месте» между Pi и экраном лежит большой аккумулятор. Размеры примерные, ±1–2 мм.

Сначала Pi в «маму» внутри, потом пазл по краямДАЯдро — плата размером с Pi с гнездом 2×20 снизу. Pi WH втыкается в него, всё остальное стыкуется к краям ядра разъёмами 1.27 мм и прижимается 4 винтами через отверстия Pi.
Всё друг с другом взаимодействует и проверяетсяДАВ каждой части пазла крошечная память с её «паспортом». При включении KODY опрашивает все части и показывает, какие вставлены и всё ли на них работает. Программа уже написана.
Аккумулятор в толстом месте, через защиту на PiДА≈ 1000 мА·ч (7 мм толщиной) между Pi и ядром. Ток идёт: аккумулятор → защита → зарядка/5 В на нижней плате → ядро → Pi. ≈ 3–4 часа работы.
ТачскринДА1.9″ IPS 170×320 с ёмкостным тачем. Рамки по бокам ≈ 8 мм — серийного экрана ровно под Pi нет.
Слева 2 кнопки + SD-картаДАSD-карту Pi достаём через окно в левой части.
Справа крутилка + такая же кнопкаДАЭнкодер с ручкой, бесконечное вращение + нажатие. Скинь фото ручки — подгоню форму.
ГироскопДАLSM6DSO (акселерометр + гироскоп) на ядре: наклон, жесты, шагомер, «встряхни — отмена».
ВибромоторчикДАНа ядре. Из проектов: «пойман сигнал — вибрируй», «наклонил — вибрируй».
GPS, скоростьДА, БЕЗ СИМ-КАРТЫДля GPS сим-карта не нужна: модуль сам ловит спутники. Скорость, координаты, точное время. Антенна внутри задней платы.
Сим-карта (мобильная связь)ПОТОМLTE-модем с SIM займёт место одного из радиомодулей и в пике берёт до 2 А. Делать отдельной сменной задней платой.
Съёмные антенны SMA и заглушкиДААнтенны накручиваются и снимаются, вместо них — заглушки-нагрузки 50 Ом. Антенны можно не класть в комплект.
USB-AУБРАНПо твоему решению: на его место встала крутилка с кнопкой.
