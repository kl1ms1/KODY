# KODY — дорожная карта

## Этап 0 — Макетка (1–3 недели, ~$60–90)

Собрать всё на проводках из готовых модулей и проверить, что идея работает.

- [ ] Pi Zero (2) WH + Raspberry Pi OS Lite (64-bit для Zero 2, 32-bit для Zero)
- [ ] Модуль экрана 2.8" ST7789 + тач → запустить `panel-mipi-dbi`, замерить FPS
- [ ] Энкодер (можно сначала обычный EC11) + 2 кнопки
- [ ] Raspberry Pi Pico (это и есть RP2040) как сопроцессор, связь по USB
- [ ] CC1101, NRF24, SX1262 — по одному модулю, проверить приём
- [ ] Светодиод + резистор на BCM26 → проект «Лампочка» из `software/`

## Этап 1 — Софт (параллельно)

- [ ] Оболочка: главное меню, статус-бар (батарея, время, Wi-Fi), настройки
- [ ] Раздел **«Проекты»**: Лампочка ✅ (прототип), Кнопка, Сервопривод,
      Датчик температуры (I2C), Реле, RGB-лента
- [ ] Раздел **Sub-GHz**: приём / запись / повтор / частотный анализатор
- [ ] **NFC / RFID**: чтение, сохранение на microSD №2, эмуляция
- [ ] **ИК**: обучение пультов, библиотека
- [ ] **LoRa**: Meshtastic-чат (`meshtasticd`)
- [ ] **SDR**: FM-радио, ADS-B (самолёты), rtl_433 (метеостанции, датчики)
- [ ] Прошивка RP2040 на C (Pico SDK), протокол обмена с Pi по USB CDC
- [ ] Обновление всего одной кнопкой

## Этап 2 — Плата v1 в EasyEDA (4–8 недель)

- Готовые ВЧ-модули на плате, RTL-SDR внутренним модулем.
- 5 плат на JLCPCB, сборка, отладка, список ошибок → v1.1.
- Корпус на 3D-принтере.

## Этап 3 — v2 / предсерия

- SDR разведён на плате, pogo-пины вместо USB-перемычки, литой корпус.
- 10–20 штук бета-тестерам.

## Что нужно, чтобы продавать

Это реально, но заранее учти:

1. **Сертификация радио.** Устройство с передатчиками нельзя легально продавать
   без сертификата/декларации: ЕАЭС (ТР ЕАЭС 020/2011 ЭМС + регистрация
   радиоэлектронных средств), ЕС (CE/RED), США (FCC). Готовые
   сертифицированные модули сильно упрощают и удешевляют это.
2. **Частоты.** Прошивка должна по умолчанию разрешать передачу только в
   разрешённых в регионе диапазонах (433.05–434.79, 868 МГц и т.д.) —
   так делает и Flipper.
3. **Законность функций.** Чтение/эмуляция своих карт, пультов и меток — ок.
   Глушилки, взлом чужих замков, копирование чужих пропусков — незаконно;
   функций «глушения» в прошивке быть не должно, это важно и для маркетплейсов.
4. **Безопасность аккумулятора.** Li-Po с защитой и NTC, транспортировка
   по правилам UN38.3 — без этого не возьмут почта/логистика.
5. Начать можно с продажи **набора «собери сам»** (плата + модули) —
   требования мягче, а аудитория (как у Flipper/Pwnagotchi) как раз такая.
